== 💡 *About the Project*

In traditional quantitative finance workflows, operations are heavily fragmented across disconnected tools: Python for research and prototyping, C++ for execution engines, external vendors for risk analytics, and separate databases for market data. This fragmentation introduces serialization overhead, network latency, code duplication, and operational bottlenecks between research and live execution.

This platform solves that problem by **centralizing the entire quantitative lifecycle into a single, cohesive, high-performance Rust ecosystem**. From real-time market data ingestion and order book management to stochastic modeling, massive Monte Carlo risk simulations, and live dashboard visualization, everything runs natively within one unified architecture—eliminating the "two-language problem" while guaranteeing memory safety and deterministic sub-microsecond latency.

== ⚙️ *Functionalities*

* *Event-Driven Trading & Execution Engine:*
** High-speed Limit Order Book (LOB) with fixed-point precision arithmetic.
** Real-time market data feed ingestion and low-latency order execution (TWAP/VWAP).
* *Real-Time Risk & Portfolio Valuation:*
** Pricing engine supporting equities, vanilla options, and path-dependent exotic derivatives (e.g., American options via Longstaff-Schwartz).
** Real-time computation of Greeks matrices, Value at Risk (VaR), stress testing scenarios, and Credit Valuation Adjustments (XVA).
* *Mathematical & Econometric Toolkit:*
** Matrix algebra, Stochastic Differential Equation (SDE) solvers, volatility surface and GARCH/EGARCH modeling, and constrained convex optimization modules.
* *Massive Parallel Simulation Engine:*
** Leverages hardware-level SIMD vectorization and lock-free multi-threading to simulate millions of Monte Carlo trajectories per second without memory contention.
* *Data & Visualization Infrastructure:*
** Zero-copy binary archiving (Apache Arrow / Parquet) paired with sequential time-series storage (QuestDB), exposed through a real-time web and native GUI dashboard.
